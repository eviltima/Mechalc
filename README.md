# Mechalc

Калькулятор с клавишами-кейкапами, звуком механической клавиатуры и ЖК-дисплеем. Статичный сайт без сборки: `index.html` и папка `assets`. На iPhone добавляется на экран «Домой» через «Поделиться» → «На экран Домой».

## Разделы

- **Обычный**: калькулятор. Деление на ноль даёт ±∞ с пояснением.
- **Инженерный**: выражения со скобками (`1+2×2`, `5×(2+2)`), sin, cos, tan, ln, log, π, e, степень, корень, проценты. Переключатель DEG/RAD над дисплеем.
- **Конвертер**: любая единица в любую, включая валюты. Единицы разной природы (например, кг и мили) дают «придуманный» результат.
- **История**: больше не отдельная вкладка. Вычисления идут прокручиваемым списком прямо над строкой выражения (в обычном и инженерном), хранятся на устройстве. Нажатие на строку возвращает результат в калькулятор, иконка рядом копирует строку, корзина в углу дисплея очищает историю.

Нажатие на число на дисплее копирует его.

## Структура репозитория

- `wrangler.jsonc`: настройки Cloudflare (имя проекта и папка с сайтом)
- `public/`: сам сайт. Всё, что внутри, становится корнем сайта
  - `index.html`: всё приложение
  - `assets/keys/`: серые вырезки кейкапов с прозрачным фоном (`cap1.png` 1u, `cap2.png` 2u, `cap_tall.png` высокая). Перекрашиваются в коде
  - `assets/sounds/mech_click.wav`: исходная запись клика (36 мс)
  - `assets/sounds/key_down_1..3.wav`, `key_up_1..2.wav`: звуки нажатия и отпускания, нарезаны из `mech_click.wav`
- `tools/slice_click.py`: скрипт нарезки (окна в миллисекундах заданы в начале файла)
  - `assets/icon-180.png`, `assets/icon-512.png`, `manifest.webmanifest`: иконка и описание для экрана «Домой»

## Выложить

1. Загрузить в репозиторий на GitHub всё содержимое этой папки так, чтобы `wrangler.jsonc` лежал в корне, а рядом папка `public`.
2. Cloudflare → Workers & Pages → Create application → Import a repository → выбрать репозиторий.
3. Настройки сборки: Build command пустой, Deploy command `npx wrangler deploy`, Root directory `/`.
4. Имя Worker в Cloudflare должно совпадать с `name` в `wrangler.jsonc` (сейчас `mechalc`). Если назвал иначе, поправь `name` в файле.
5. Сайт откроется по адресу `mechalc.<твой-поддомен>.workers.dev` и будет обновляться при каждом push в `main`.

## Что менять

- **Курсы валют**: в приложении, настройки (значок справа вверху) → «Курсы к тенге». Стартовые значения ориентировочные, лежат в `public/index.html`, в константе `DEF`.
- **Результат для несовместимых единиц**: функции `absurd` и `crossNote` в `public/index.html`. Сейчас это стабильный «курс Вселенной» для каждой пары. Любое другое правило и текст меняются там же.
- **Звук клавиш**: при нажатии играет случайный из `key_down_*.wav`, при отпускании случайный из `key_up_*.wav` (тише; выключается переключателем «Звук отпускания» в настройках). Свои варианты: положи WAV в `assets/sounds/` и допиши в `SOUNDS.down` / `SOUNDS.up`. Нарезать заново из другой записи: поправь окна в `tools/slice_click.py` и запусти `python3 tools/slice_click.py запись.wav`.
- **Звуки пуллера**: `keycap_pull_1..3.wav` (снятие) и `keycap_insert_1..3.wav` (посадка). Это синтетические заглушки: положи свои WAV с теми же именами. Список файлов лежит в константе `SOUNDS` в `index.html`, можно добавлять варианты: каждый раз играет случайный.
- **Курсы валют**: подтягиваются из сети при открытии (не чаще раза в 6 часов), источник open.er-api.com, запасной jsDelivr. Значения в настройках можно править вручную до следующего обновления.
- **Раскладка**: константа `BASE`. Справа налево по рядам: `± % CLEAR UNDO =`, `7 8 9 ÷ BACKSPACE`, `4 5 6 × √`, `1 2 3 − [пусто]`, `0 , + PULLER`. Клавиша `['', 'blank', 'fn']` свободная: без надписи и действия. Чтобы дать ей функцию, поменяй надпись и ключ и добавь ветку в `calcKey`/`engKey`.
- **Наборы по умолчанию**: два первых пресета, «Цифры» (серый, для цифр) и «Функции» (оранжевый, для остальных клавиш). Кнопка «Сбросить клавиши к стандартным» в настройках возвращает цвета пресетов и снимает все посаженные пуллером кейкапы, клавиши снова берут эти два набора. Цвета «Кейкапы: цифры» и «функции и акцент» в оформлении правят именно их.
- **Настройки** применяются сразу, кнопки подтверждения нет; закрыть можно крестиком, Esc или нажатием мимо окна.
- **Конвертер**: кнопка со стрелками между строками дисплея меняет единицы местами (плюс клавиша ⇄ на клавиатуре).
- **Фон**: серый градиент и шершавая текстура (`body::before`, `body::after`: сила задаётся `opacity`).
- **Пресеты кейкапов**: у каждой ячейки меню пуллера (14 штук) свой цвет, меняется в настройках → «Пресеты кейкапов». Цвет надписи подбирается по яркости. Клавиши с уже посаженным пресетом перекрашиваются сразу. Список пресетов и их исходные цвета: константа `KITS`.
- **Язык**: настройки → «Язык». Русский, English, Қазақша; по умолчанию берётся язык браузера. Тексты лежат в словаре `TR` в начале скрипта (ключ = русская строка). Чтобы добавить язык, допиши его в `LANGS` и `TR`: что не переведено, показывается по-русски. Надписи на самих кейкапах (UNDO, BACK SPACE и т. д.) не переводятся.
- **Скругление клавиш**: константа `CAPR` в `tintURL` (доля ширины клавиши, сейчас .125). Больше число, круглее углы.
- **Свои настройки**: фон, цвета и картинка кейкапов, шрифт дисплея и свои звуки задаются в настройках приложения. Это личные данные устройства (localStorage и IndexedDB браузера), в репозиторий они не попадают и между устройствами не синхронизируются.
- **Клавиши**: растровые вырезки из `assets/keys/` перекрашиваются в нужный цвет на лету (функция `tintURL`): серая картинка работает как карта света и тени, поэтому скосы, блики и зерно пластика сохраняются при любом цвете. Яркость лицевой грани в файлах нормализована до 170, это число зашито в `tintURL`. Если заменишь картинки, сохрани серый тон и прозрачный фон, а положение грани поправь в `CAPS[..].face`. Векторная отрисовка `capSVGv` осталась запасным вариантом, если картинки не загрузились.
- **Акцент интерфейса**: цвет цифр дисплея, вкладок, кнопок и ползунков берётся из цвета клавиши «=» (функция `applyAccent`). Меняешь цвет «Кейкапы: функции и акцент» или ставишь пуллером другой кейкап на «=», и всё остальное перекрашивается следом.
- **Шрифт клавиш**: в настройках список готовых шрифтов или свой файл (ttf, otf, woff, woff2). Применяется ко всем клавишам. Файл хранится в IndexedDB устройства.
- **Надписи**: эффект краски, залитой в выемку, делает SVG-фильтр `engrave` (тень от верхней стенки внутри буквы и светлая кромка снизу). Силу эффекта можно менять в его параметрах в начале `<body>`.
- **Заставка**: из-под клавиатуры видны голые свичи, кейкапы залетают со случайных сторон в случайном порядке. Логика в функции `intro`.
- **Открывать нужно по http(s)**, не двойным кликом по файлу: из `file://` браузер не даст прочитать пиксели картинок для перекраски (включится запасная векторная отрисовка), а звуки не загрузятся.
