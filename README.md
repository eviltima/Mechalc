# Калькулятор с конвертером валют

Статичный сайт без сборки: `index.html` и папка `assets`. Работает на iPhone, на экран «Домой» добавляется через «Поделиться» → «На экран Домой».

## Что внутри

- `index.html`: калькулятор, конвертер валют, звук механической клавиатуры, настройки
- `assets/keys/`: клавиши (WebP с прозрачным фоном), по одной на кнопку
- `assets/sounds/mech_click.wav`: звук нажатия клавиши
- `assets/icon-180.png`, `assets/icon-512.png`: иконка для экрана «Домой»
- `manifest.webmanifest`: описание приложения для Android и Chrome

## Выложить на GitHub

1. Создай репозиторий и загрузи в его корень всё содержимое этой папки (`index.html` должен лежать в корне).
2. Если нужен GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Выложить на Cloudflare

Через GitHub (рекомендуется, сайт обновляется при каждом push):

1. Cloudflare → Workers & Pages → создать проект → подключить Git → выбрать репозиторий.
2. Build command оставить пустым. Output directory: `/` (корень).
3. Сохранить и задеплоить. Домен добавляется в настройках проекта (Custom domains).

Без GitHub: в том же разделе выбрать Direct Upload и перетащить папку.

Если в панели Cloudflare Pages уже нет, используй вариант со статичными файлами для Workers (Workers Static Assets): те же файлы, каталог с сайтом указывается как каталог ассетов.

## Курсы валют

Стартовые курсы ориентировочные и лежат в `index.html`, в константе `DEF`. Любой курс можно поправить в приложении: настройки (кнопка справа вверху) → «Курсы к тенге». Значения сохраняются на устройстве.

## Звук

При нажатии проигрывается `assets/sounds/mech_click.wav`. Тон слегка меняется от клавиши к клавише (операторы и «=» ниже), поэтому звук не звучит одинаково. Чтобы заменить звук, положи новый файл с тем же именем (лучше короткий, до 100 мс). Если файл не загрузился, включается встроенный синтезированный щелчок.

## Заменить клавиши

Файлы в `assets/keys/` подключаются по именам в массивах `CALC` и `CONV` в `index.html`. Чтобы заменить клавишу, положи новый файл с тем же именем.
